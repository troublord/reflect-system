# Reflect System

一個練習用的活動 / 目標追蹤系統，用 Spring Boot + Thymeleaf + MySQL 打造的伺服器端渲染網頁應用。

> **狀態：練習專案 / 未完成（2023 年）**
> 這是我早期練習 Spring Boot 全端開發（後端 + 伺服器渲染頁面 + 資料庫 + 登入驗證）的 side project，2023-03 開始、2023-05 停止，沒有部署上線過，部分功能（如總覽頁）做到一半就停了。
>
> 這個專案的資料模型（活動、動作、標籤、目標）跟後來做的 [MyMomentum](https://github.com/troublord/my-momentum) 是同一個方向的延伸——MyMomentum 是把這個構想重新用 React + Spring Boot 全端架構完整做完、真正上線的版本。

## 這是什麼

一個記錄「活動」與底下「動作」的個人追蹤系統，構想上想解決的問題：

- 使用者登入、註冊自己的帳號
- 建立「活動（Activity）」，每個活動有狀態（例如 Inactive）
- 活動底下可以記錄「動作（Action）」
- 用「標籤（Tag）」分類
- 規劃了「目標（Goal）」功能（尚未串接完成）

## 技術架構

| 部分 | 技術 |
|---|---|
| 後端 | Spring Boot 3、Java 17 |
| 頁面渲染 | Thymeleaf（伺服器端渲染，非前後端分離） |
| 資料庫 | MySQL、Spring Data JPA |
| 驗證 | Spring Security（登入、註冊、角色權限） |

## 目前完成度

已可運作：登入、註冊（含表單驗證）、首頁。

未完成：總覽頁（`/overview`）取得資料的邏輯已寫但被註解掉，尚未串接；`Goal`（目標）實體已設計但沒有對應的功能頁面。
